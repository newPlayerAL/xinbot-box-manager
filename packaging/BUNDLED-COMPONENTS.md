# Bundled components

[简体中文](BUNDLED-COMPONENTS.zh-CN.md)

The complete Debian package contains unmodified official release binaries from the following
projects. Each component is licensed under GPL-3.0-or-later by its respective authors and
contributors.

| Installed file | Component | Version | Corresponding source |
| --- | --- | --- | --- |
| `xinbot.jar` | XinBot Core | 2.4.3-RELEASE | <https://github.com/huangdihd/xinbot/tree/2.4.3-RELEASE> |
| `xinmetaplugin.jar` | XinMetaPlugin | 1.1.0-RELEASE | <https://github.com/huangdihd/XinMetaPlugin/tree/1.1.0-RELEASE> |
| `backtothebase.jar` | BackToTheBase | 1.8.0-RELEASE | <https://github.com/huangdihd/BackToTheBase/tree/1.8.0-RELEASE> |
| `movementsync.jar` | MovementSync | 1.6.0-RELEASE | <https://github.com/huangdihd/MovementSync/tree/1.6.0-RELEASE> |

Exact binary download URLs and SHA-256 values are recorded in `bundled-components.tsv` beside this
document in an installed package, and in `packaging/bundle-resources.tsv` in the source repository.
The complete GPL-3.0 license text is installed as `copyright` in the same directory.
